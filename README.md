### 1. Nova — мой собственный ИИ-ассистент

**Python · AI · Speech Recognition · Memory · Context Management**

[**Открыть репозиторий Nova →**](https://github.com/BoCXoD-man/Nova)

Nova — мой личный проект и хобби, в котором я исследую, каким должен быть действительно полезный ИИ-ассистент.

#### 💡 История создания

Идея Nova родилась из простого вопроса: почему «умные» ассистенты зачастую оказываются не такими уж умными?

Мне хотелось большего, чем колонка, которая умеет сообщить погоду, включить музыку или выполнить несколько заранее предусмотренных команд. Я захотел попробовать создать собственного ассистента — более гибкого, контекстного и интересного в общении.

Так началась разработка Nova.

Моя цель — создать не просто голосовую оболочку для набора команд, а полноценного цифрового помощника, который сможет работать с контекстом, сохранять полезную информацию, обрабатывать запросы и становиться более полезным в повседневной работе.

Nova развивается постепенно: я экспериментирую с архитектурой, механизмами памяти и обработки запросов, изучаю новые подходы и проверяю собственные идеи на практике.

Для меня этот проект — возможность не только изучать технологии искусственного интеллекта, но и самостоятельно формировать представление о том, каким должен быть удобный цифровой помощник.

#### Что я развиваю в проекте

- Модульную архитектуру с разделением ответственности между компонентами.
- Голосовое взаимодействие и распознавание речи.
- Обработку команд и пользовательских запросов.
- Управление контекстом и хранение пользовательской информации.
- Интеграцию ИИ-компонентов в общую систему ассистента.

**Nova — это мой долгосрочный эксперимент на стыке Python, ИИ и идеи персонального цифрового помощника.**

### 3. Telegram Cloud Storage Bot — коммерческий проект

**Python · Telegram Bot API · Google Drive API · Yandex Disk REST API**

[**Открыть репозиторий →**](https://github.com/BoCXoD-man/Telegram-Cloud-Storage-Bot)

Один из моих недавних коммерческих проектов — Telegram-бот для работы со ссылками на облачные хранилища Google Drive и Yandex Disk.

Бот получает информацию о публичных ресурсах и содержимом облачных хранилищ, после чего представляет результаты пользователю в Telegram.

#### Реализованные возможности

- Обработка ссылок на Google Drive и Yandex Disk.
- Получение списка файлов Google Drive.
- Работа с публичными ресурсами Yandex Disk.
- Автоматическое определение типа переданной ссылки.
- Получение названий и типов файлов.
- Обработка ошибок API и недоступных ресурсов.
- Настройка параметров через переменные окружения.
- Авторизация в Google Drive API с использованием Service Account.
- Настройка HTTP-таймаутов и обработка длинных сообщений Telegram.

В этом проекте я решал прикладную задачу, связанную с интеграцией нескольких внешних сервисов, обработкой их ответов и передачей информации через Telegram.
