## ⭐ Featured Projects

### 🤖 [Nova — Local Voice AI Assistant](https://github.com/BoCXoD-man/Nova)

**Мой основной и самый масштабный pet-project.**

Локальный голосовой ассистент на Python, который объединяет распознавание речи, языковую модель, обработку команд, контекст, память и внешние инструменты. Проект развивается как модульная система, в которой отдельные компоненты отвечают за голосовой ввод и вывод, работу с LLM, управление контекстом, выполнение команд и хранение данных.

**Что исследую и реализую:**
- голосовой ввод и распознавание речи с Whisper;
- взаимодействие с локальными LLM, включая Qwen через llama.cpp;
- обработку структурированных команд и маршрутизацию действий;
- долговременную память и подбор релевантного контекста;
- интеграцию с внешними API и инструментами;
- модульную архитектуру, конфигурацию и логирование.

**Стек:** `Python` · `SQLite` · `SQLAlchemy` · `llama.cpp` · `Qwen` · `Whisper` · `REST API`

Nova — мой способ изучать не только отдельные библиотеки, но и то, как спроектировать и постепенно развивать приложение из множества взаимодействующих компонентов.

### 🎓 [EduForge — AI Tool for Learning Materials](https://github.com/BoCXoD-man/EduForge)

Настольное приложение для работы с учебными материалами с использованием языковых моделей. В проекте можно взаимодействовать с разными AI-провайдерами через единый интерфейс, не привязывая основную логику к одному сервису.

**Что особенно интересно в реализации:**
- интеграция OpenAI, Gemini и OpenRouter;
- единый интерфейс для разных провайдеров;
- организация создания провайдеров через Factory Pattern;
- фоновое выполнение задач, чтобы интерфейс оставался отзывчивым;
- разработка настольного приложения на PySide6.

**Стек:** `Python` · `PySide6` · `LLM` · `OpenAI API` · `Gemini` · `OpenRouter` · `Threads` · `Factory Pattern`

### ☁️ [Telegram Cloud Storage Bot](https://github.com/BoCXoD-man/Telegram-Cloud-Storage-Bot)

Коммерческий проект — Telegram-бот для взаимодействия с облачными хранилищами. Он связывает Telegram с внешними API и помогает работать с файлами и ссылками из привычного интерфейса мессенджера.
